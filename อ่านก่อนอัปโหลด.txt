DocDesk — ไฟล์สำหรับอัปโหลดขึ้น GitHub
=========================================

*** สำคัญมาก ***
ตอนอัปโหลดขึ้น GitHub ให้ "เข้ามาในโฟลเดอร์นี้ก่อน"
แล้วกด Ctrl+A เลือกไฟล์ทั้งหมด จากนั้นค่อยลากขึ้นเว็บ

ห้ามลากตัวโฟลเดอร์ docdesk-github ขึ้นไปทั้งอัน
เพราะไฟล์จะไปอยู่ในโฟลเดอร์ย่อย ทำให้เว็บเปิดไม่ขึ้น (ขึ้น 404)

-----------------------------------------
รายการไฟล์ทั้งหมด 13 ไฟล์ (รวมไฟล์นี้)
-----------------------------------------
index.html              ตัวโปรแกรม DocDesk (ห้ามเปลี่ยนชื่อ)
README.md               หน้าแนะนำโปรเจกต์บน GitHub
LICENSE                 สัญญาอนุญาต MIT
THIRD-PARTY.md          เครดิตไลบรารีที่ใช้
.nojekyll               ไฟล์เปล่า บอก GitHub ให้เสิร์ฟไฟล์ตามที่เห็น
.gitattributes          ตั้งค่าให้ Git จัดการไฟล์ใหญ่ได้ดีขึ้น
docdesk-icon.svg        โลโก้ (สัญลักษณ์อย่างเดียว)
docdesk-logo-dark.svg   โลโก้เต็มสำหรับพื้นหลังเข้ม
docdesk-logo-light.svg  โลโก้เต็มสำหรับพื้นหลังสว่าง
docdesk-icon-192.png    ไอคอนแอปขนาด 192px
docdesk-icon-512.png    ไอคอนแอปขนาด 512px
favicon-32.png          ไอคอนสำรองสำหรับเบราว์เซอร์รุ่นเก่า

หมายเหตุ: ไฟล์ .nojekyll และ .gitattributes ขึ้นต้นด้วยจุด
Windows จะซ่อนไว้ ถ้ามองไม่เห็นให้เปิด File Explorer
แล้วไปที่แท็บ View > ติ๊ก Hidden items

ไฟล์ "อ่านก่อนอัปโหลด.txt" นี้ ไม่ต้องอัปขึ้น GitHub ก็ได้
(จะอัปไปด้วยก็ไม่เสียหาย แค่มีไฟล์เกินมา 1 ไฟล์)

-----------------------------------------
ขั้นตอนโดยย่อ
-----------------------------------------
1. สมัคร github.com/signup  (เปิด 2FA ด้วย)
2. สร้าง repository ชื่อ docdesk แบบ Public
3. กด uploading an existing file แล้วลากไฟล์ทั้งหมดขึ้นไป
4. Settings > Pages > Deploy from a branch > main / (root) > Save
5. รอ 1-2 นาที จะได้ลิงก์เว็บ

รายละเอียดเต็มดูในไฟล์ "คู่มือสมัคร-GitHub-ทีละขั้น.html"
