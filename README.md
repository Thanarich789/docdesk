## เครื่องมือทั้งหมด

### จัดการ PDF
| | |
|---|---|
| **รวมไฟล์** | รวม PDF และรูปภาพหลายไฟล์เป็นเล่มเดียว จัดลำดับได้ |
| **แยกไฟล์** | แยกทีละหน้า · ตามช่วง · ทุก N หน้า · ดึงเฉพาะหน้าที่ต้องการ |
| **จัดการหน้า** | ลบ · หมุน · สลับลำดับ พร้อมภาพตัวอย่างทุกหน้า |
| **ครอบตัดหน้า** | ตัดขอบกระดาษส่วนเกิน |
| **บีบอัด PDF** | ลดขนาดไฟล์ให้ส่งอีเมลผ่าน |
| **ใส่ลายน้ำ** | ข้อความภาษาไทยได้เต็มรูปแบบ ปรับสี องศา ความจาง |
| **ใส่เลขหน้า** | 5 รูปแบบ 5 ตำแหน่ง |
| **ใส่/ปลดรหัสผ่าน** | ป้องกันเอกสารสำคัญ |
| **แก้ไข PDF** | ปิดทับ · ไฮไลต์ · พิมพ์ข้อความ · เซ็นชื่อ · แปะรูป |

### แปลงไฟล์
| | |
|---|---|
| **PDF → Excel** | ตรวจจับตารางจากพิกัดตัวอักษรจริง ตัวเลขนำไปคำนวณต่อได้ทันที |
| **PDF → Word** | คงหัวข้อ ย่อหน้า และตาราง เปิดแก้ไขใน Word ได้ |
| **PDF → รูปภาพ** | JPG · PNG · WebP เลือกความละเอียด 72–288 DPI |
| **รูปภาพ → PDF** | รวมเล่มเดียวหรือแยกไฟล์ เลือกขนาดกระดาษได้ |
| **ดึงข้อความ** | คัดลอกข้อความจาก PDF ไปใช้ต่อ |

### รูปภาพ
| | |
|---|---|
| **แปลงรูปภาพ** | HEIC (iPhone) · TIFF · AVIF · SVG ↔ JPG · PNG · WebP |
| **ย่อขนาดไฟล์รูป** | กำหนดเป้าหมายเป็น KB ระบบไล่ปรับคุณภาพให้อัตโนมัติ |
| **ขยาย/ปรับขนาดภาพ** | ขยายภาพเล็กหรือเบลอ ให้ใหญ่ขึ้นสูงสุด 4 เท่า ด้วย Lanczos + ลับคม ลดจุดรบกวน ปรับแสง พร้อมแถบเลื่อนเทียบก่อน–หลัง และสวิตช์พื้นหลังโปร่งใส (PNG) · โหมดปรับขนาดตามสื่อ: รูปติดบัตร 1/1.5/2 นิ้ว, A4, สไลด์ 16:9, ป้ายไวนิล หรือกำหนดเอง (px/นิ้ว/ซม. + DPI) พร้อมฝังค่า DPI ในไฟล์ |
| **ลบพื้นหลัง** | แยกวัตถุออกจากพื้นหลังสีเดียว |
| **ลบ/ย้ายวัตถุในภาพ** | ลบคน สิ่งของ ลายน้ำ แล้วเติมพื้นที่ให้กลมกลืน · เลือกด้วย AI (SlimSAM คลิกจุดหรือลากกรอบ) · Magic · Lasso · แปรง · **🧲 Magic Grab ยก–ย้าย–คัดลอก–ย่อขยาย–หมุนวัตถุ** พร้อมเติมพื้นหลังที่เดิมอัตโนมัติ (ขยายพื้นที่ลบกันเงาค้าง) · และ **ลบพื้นหลังด้วย AI** (เก็บเฉพาะที่เลือก ใช้กับพื้นหลังหลายสีได้) |

## จุดเด่น

- 🔒 **ไฟล์ไม่ออกจากเครื่อง** — ทุกอย่างประมวลผลในเบราว์เซอร์ ต่างจากเว็บทั่วไปที่ต้องอัปโหลดไฟล์ให้เขา
- 👀 **เห็นภาพตัวอย่างก่อนยืนยัน** ทุกเครื่องมือ กันเลือกไฟล์ผิด
- 🇹🇭 **ภาษาไทยสมบูรณ์** ทั้งหน้าจอ ลายน้ำ และข้อความในเอกสาร
- 🌗 ธีมสว่าง/มืด + เลือกสกินสีได้ 6 แบบ

## ข้อจำกัดที่ควรทราบ

- **PDF → Excel / Word** ใช้ได้กับไฟล์ที่มีข้อความจริง ไม่รองรับเอกสารสแกน (ยังไม่มี OCR)
- **PDF → Word** ไม่คงตำแหน่งรูปภาพและหัว–ท้ายกระดาษ เพราะ PDF ไม่ได้เก็บโครงสร้างเอกสารไว้
- **บีบอัด PDF** แปลงหน้าเป็นภาพ ทำให้ค้นหาข้อความ (Ctrl+F) ไม่ได้
- ไม่รองรับ `.doc` รุ่นเก่า · `.psd` · `.ai` แบบ native
- ต้องต่ออินเทอร์เน็ตครั้งแรกเพื่อดึงไลบรารี (ครั้งต่อไปเบราว์เซอร์จำไว้ให้)
- **ลบวัตถุ — AI** ดาวน์โหลดโมเดลครั้งแรกประมาณ 30–40 MB (โหลดเมื่อกดเปิดใช้ AI เท่านั้น) · ลบพื้นที่ใหญ่บนลวดลายซับซ้อนอาจไม่เนียน
- ถ้าดาวน์โหลดไปใช้ในเครื่อง ต้องวาง `eraser.html` และ `upscaler.html` ไว้โฟลเดอร์เดียวกับ `index.html`
